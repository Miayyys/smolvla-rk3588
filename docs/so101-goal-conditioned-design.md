# SO101目标条件化分层策略：结构设计与实验B结果（B未明显优于A，按规则停止）

日期：2026-10-16。分支：`experiment/so101-goal-conditioned`。

本文件只记录设计和实验计划。以下所有结构、参数和预期都尚未实现或测量；结果出来后在本文件追加实验记录，再据证据修改[项目路线](project-route.md)。

## 1. 目的与边界

- 目标：先在PC（GPU仿真）上改善SO101抓放闭环效果，解决逐步动作误差累积导致的抓取失败。
- RK3588部署推迟。凡是只和板端有关的事项（RKLLM导出、RKNN图、板端延迟）不在本阶段确定，见第8节。
- 这是一个新模型版本。它的FP基线、量化和部署结果不能与原SmolVLA的量化结论混用。

## 2. 依据（已有记录）

- [SO101仿真策略诊断](so101-sim-policy-diagnosis.md)：单场景过拟合后，闭环接近阶段仍有1–3°关节偏差，张开的手指先把方块推开；示教对0.5°固定偏置即只剩3/6完成，2°时0/6。
- [SO101脚本专家数据](so101-scripted-data.md)：6000步全量训练后，30个验证种子上每块执行50步0/30完成，每块执行10步4/30完成、7/30抓住；训练帧与验证帧离线误差几乎相同，判断主要是训练不足，其次是块内误差累积。抓空后策略仍按示教时序继续搬运。
- 脚本专家（`qvla/evaluation/so101_scripted_expert.py`）本身按阶段执行：`pregrasp`先停在沿接近方向后退0.07m处，再慢速`descend`；阶段切换由距离阈值、停滞步数和超时规则决定。训练数据已按种子在粗移动阶段加入0/1/2°执行噪声，记录的是干净专家标签（DART方式）。

据此判断：只把任务拆成多句语言子目标不会提高精度；需要给下层一个精确的几何目标，并用最新本体状态闭环修正，同时显式处理抓空。

## 3. 结构

```
慢环（每次VLM推理）: 图像×2 + 语言 + state_{t-k} ─► VLM（冻结）─► prefix KV（给Expert）
                                                            └─► 规划头·视觉部分 ─► 视觉特征（缓存）
快环（控制频率）:    state_t ─► FK ─► 当前TCP、夹爪开度
                     视觉特征 + state_t ─► 规划头·快速部分 ─► 阶段logits、目标位姿、目标开口
                     ─► 规则门控 ─► 当前阶段
                     ─► Δ = 目标 − 当前TCP ─► goal_proj ─► goal token
Expert:              prefix KV + [goal token, 50个带噪动作token] ─► 动作块
```

- goal token放在Expert的suffix中，不进入VLM prefix：VLM每次推理只跑一遍，prefix长度不变。
- `goal_proj`最后一层零初始化，训练初期行为接近原模型。
- 阶段沿用数据中的9类：`pregrasp, descend, close, lift, carry, lower, open, retreat, hold`。

### 3.1 规划头

| | 内容 |
|---|---|
| 输入（慢部分） | VLM最后一层prefix特征（两路图像、语言、state token），1–2个可学习query做一层cross-attention池化 |
| 输入（快部分） | 慢部分特征 + 最新state_t，小MLP，可每个控制周期运行 |
| 不输入 | 历史阶段（避免学成复制上一阶段，阶段连续性由门控保证） |
| 输出 | 阶段logits(9)；目标TCP位置(3，基座坐标系)；目标TCP姿态(6D表示)；本阶段目标夹爪开口(1) |

### 3.2 goal token（20维）

| 字段 | 维度 |
|---|---|
| 门控后阶段one-hot | 9 |
| Δp = 目标位置 − FK(state_t) | 3 |
| ΔR（当前到目标的相对旋转，6D） | 6 |
| 目标夹爪开口 | 1 |
| ‖Δp‖ | 1 |

最新state只通过Δ和规划头快部分进入模型；prefix中的state token与图像同一时刻（t−k）。

## 4. 阶段门控（规则）

- 只允许保持或进入下一阶段。
- 到达条件沿用脚本专家参数（距离阈值、停滞步数、`lower`超时），并要求规划头阶段预测连续k次一致才切换。
- `lift/carry`中夹爪开度接近完全闭合（判为抓空）时退回`pregrasp`。
- 超时退回上一阶段或记为失败。

数据只存成功回合，但脚本专家抓空后会有限次重试：`manifest.json`中训练集350段有30段`attempts=2`（验证3/27，测试3/43），因此含少量“抓空→重抓”恢复样本，约占回合9%，单个恢复片段的帧占比更低（未统计）。样本稀少，失败恢复先用规则；之后对比规则与学习式切换，必要时增加恢复数据。

## 5. 训练

### 5.1 标签补录

在`generate_so101_scripted_data.py`的`record()`中每帧补存：TCP位姿、物体位姿、专家`_goal()`返回的目标位置/姿态、本阶段目标夹爪开口。用原种子和原划分重新生成，确认与v1数据state一致。FK需要先核对数据集行到仿真qpos的反向转换，FK结果与仿真TCP的误差应低于1mm。

### 5.2 loss与梯度

- Expert：沿用SmolVLA流匹配。`x_τ = τ·ε + (1−τ)·A`，目标`u = ε − A`，`L_flow = mean(mask·(v−u)²)`，mask去掉填充动作维。条件为加噪真值目标构成的goal token。梯度回到Expert、`goal_proj`、`state_proj`、动作/时间投影层；VLM冻结。
- 规划头：`L_planner = λ_ph·加权CE(阶段) + λ_p·Huber(位置) + λ_R·测地角误差(姿态) + λ_w·L1(开口)`。阶段按训练帧逆频率加权。梯度只回到规划头。
- 两个loss可在同一step计算，共用一次VLM前向；参数不相交，梯度不相通。规划头输出喂给Expert时一律`detach()`，保持其位姿含义并便于分层定位问题。

### 5.3 增强

- 目标噪声：位置约1cm、姿态约5°（初值），之后改为规划头验证集实测误差分布。
- 空目标：10%概率换成可学习的空目标token。
- 视觉延迟：图像和prefix state取t−k帧，Δ、规划头快部分state和标签取t帧。PC同步评测阶段先取k=0；加入异步延迟评测时，k范围取GPU实测延迟。

### 5.4 阶段

1. Expert + 真值目标（teacher forcing）。
2. 规划头单独训练（可离线缓存VLM特征）。
3. 可选：以比例p_mix用规划头预测目标替换真值，继续微调Expert。

## 6. 实验顺序与对照

所有对照使用同一份数据、同一组验证种子、固定初始噪声与种子；测试种子在最终比较前不使用。

| 编号 | 配置 | 回答的问题 |
|---|---|---|
| A | 原SmolVLA，同数据训练到验证收敛 | 基线；排除“只是训练更久”的影响 |
| B | Expert + 真值目标 | 给定准确目标时下层能否精确到达 |
| C | B + 不同幅度目标噪声 | 规划头需要的精度 |
| D | 完整结构（规划头预测目标 + 门控） | 整体是否优于A |
| E | goal token只含阶段、不含位姿 | 位姿信息是否必要 |

顺序：补录标签 → A训练到收敛 → B。B不明显优于A则停止该方向，不训练规划头。

指标：闭环完成率与抓住率（主指标），最近TCP距离，抓空后是否重抓；规划头阶段准确率、目标位置误差（mm）、姿态误差（°）；离线动作MAE只用于筛选。

- 板端视觉延迟及k范围。
- RKLLM补丁能否导出最后一层hidden state；不能则规划头改读最后一层KV。
- Expert RKNN图新增goal输入（20维向量经MLP加到动作token上，suffix长度保持50，见第10节）。
- 新增层进入HAQ节点枚举，重新建立该模型的FP基线和量化流程。
- 真机FK所需运动学参数、关节零位与方向的物理验证。

### 10.2 实现中的取舍

- **目标注入方式**：goal向量（第3.2节，20维）经MLP（最后一层零初始化）后**加到全部50个动作token**，而不是作为额外token放进suffix。原因：单独的零向量token仍参与注意力softmax（其key为0，得分为0但占权重），会改变初始输出；相加方式在零初始化时与原模型逐位相同（已验证，见10.4），且suffix长度、注意力掩码和位置编码不变，对之后的RKNN导出更简单。仍只作用于Expert侧，VLM prefix不变。
- **空目标**：10%概率用可学习的空目标嵌入（零初始化）替换整个目标嵌入。
- **坐标系**：场景中机器人`base`体位于世界原点、姿态为单位四元数，世界坐标即基座坐标；Δp用世界坐标，ΔR取`R_tcp^T R_goal`（当前TCP坐标系），6D为前两列。Δp、‖Δp‖除以0.1m，开口除以100。
- **目标开口**：脚本专家的夹爪终值只由阶段决定（pregrasp/descend张开0.9rad=55.97，close/lift/carry/lower闭合−0.17rad=0.24，open/retreat/hold松开0.55rad=37.74，数据单位0–100）；因此开口由阶段查表，规划头仍预测它以保留设计字段。
- **目标噪声**（训练）：位置每轴σ=1cm/√3（RMS范数1cm），姿态绕随机轴转角~N(0,5°)；在GPU上用全局随机数生成。
- **规划头**：2个可学习query对VLM最后一层prefix隐状态（已过最终norm、detach）做cross-attention（8头）→LayerNorm+Linear到256维（慢部分）；与归一化关节state拼接经两层MLP（快部分）；输出阶段logits、绝对目标位置（×0.1m）、6D姿态（Gram-Schmidt）、开口（×100）。参数433万。
- **loss**：Expert为原SmolVLA流匹配（同样的填充掩码与归约）；规划头为逆频率加权CE + 位置Huber（cm，δ=1cm）+ 测地角/10° + 开口L1/10，各项权重1，整体权重1。两组参数各自梯度裁剪（均为10）；VLM冻结。
- **离线验证**：动作MAE用记录的真值目标（无噪声、无空目标），即B的条件；同时记录规划头阶段准确率、位置/姿态误差中位数、开口误差。best仍按动作MAE选择。
- **闭环评测**（`so101_goal_eval.py`）：脚本专家与策略并行，每个控制步按机器人实测状态推进其阶段规则（到达/停滞/超时、抬起后抓取检查、有限次重抓），即第4节的规则门控；每块开始时用专家当前阶段与目标位姿、当前关节FK得到goal向量。专家自身的关节命令不执行。C的目标噪声用独立随机数生成器，与流匹配初始噪声分开。这一评测读取仿真真值，只是诊断上限，不可部署。

### 11.3 评测的运行间随机性（新发现）

同一模型、同一命令在种子100003/100006/100018上连续跑两次，结果不同（100006一次完成、一次未完成）。逐项排查（`scripts/so101_eval_determinism_probe.py`、`scripts/so101_render_determinism_probe.py`）：物理对同一命令序列可复现（状态差0）；策略对同一输入与种子可复现（bf16、fp32各自重复差0）；但同一种子重置后渲染不完全相同：顶视76800个像素中0–2个像素差1个灰度级，腕部相机后续步也出现差异，模型与光照参数完全相同，判断为EGL光栅化的微小非确定性。该差异经策略（同一输入bf16与fp32输出最大差3.6）和接触动力学放大后，整条轨迹分叉。因此**单个种子的闭环结果不可逐次复现，30种子完成数的运行间波动约±2**（A为3–5，B为1–4）；此前GPUServer上的各次30/100种子结果也带有这一波动。门控2次与5次两次评测的差异（1/30 vs 4/30，且5次的4个完成都在第一次尝试）主要来自这一波动，不能归因于门控次数。

### 11.4 结论（限于本实验条件）

- 给Expert准确的几何目标后，**接近明显改善且稳定**：最近TCP中位数约7mm（A约14mm），≤10mm的种子约19–21个（A 10–12），从未接近的种子4个（A约10）；空目标时退化到26mm、只有2段抓住，说明模型确实依赖目标输入。
- **完成率没有改善**：B三次1/4/2（均值2.3/30），A三次3/3/5（均值3.7/30），差异在运行间波动内；抓住数略多（12–13 vs 9–10）。失败从“到不了方块”转为“抓住后掉落、放不准”。
- 按第6节规则（B不明显优于A则停止），**目标条件化方向在当前形式下停止**，不训练规划头的后续阶段、不做C/D。
- 结论边界：B只训到5000步，A为10000步，二者步数不等（A在第5000与10000步的服务器评测都是3/30）；只有30个种子、每个条件1–3次；目标来自仿真真值，是上限诊断。抓取保持与放置失败的原因（闭爪时机、抓取点、抬起速度、夹持力）未分析。
- 记录的瓶颈转移提示下一步应针对抓取与搬运阶段：例如分析B抓住后掉落的回合、在失败状态上补充专家纠偏数据（DAgger式），而不是继续增加目标/规划结构。以上为建议，未实施。
