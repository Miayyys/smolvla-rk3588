## 每页固定记录项

1. **问题与假设**：要验证哪个量化误差或硬件约束；事先写成功/失败判据，不能看冻结测试结果后修改。
2. **原理与公式**：使用的 quantizer、clipping、scale、zero point、舍入和梯度规则；注明论文或工具文档。写清公式对应输入张量和统计维度。
3. **可复现配置**：代码/模型/processor/data 修订号与 SHA，环境版本，episode 划分、采样数、随机种子、输入 shape，模块名单，位宽、粒度、量化范围、校准方法、训练参数、完整命令；缺失项填“未记录”，不能推测。
4. **计算过程与图**：保存未处理的逐样本/逐层统计、候选参数扫描表和绘图脚本。图的横纵轴、单位、样本量与数据集应可从图注读出；每个图附原始数据路径。展示所有关键候选，不能只展示选中的结果。
5. **选择与结果**：说明选择了哪个阈值/层/位宽，依据哪个开发指标；记录选中前后 FP、QAT、PTQ 的动作、闭环、真实文件字节、延迟和内存。同一输入/种子做配对比较；没测的指标填“未测量”。MSE、离线动作 MAE 和子图输出误差只用来预筛，最终位宽还须依据闭环任务质量与硬件约束决定。
6. **作用范围与下一步**：结论仅适用于哪些模块/后端；警告或失败日志；下一实验要解决什么。先完成记录再扩展实验。

### 截断/KL 校准记录格式

若某层尝试 KL 截断，应在该层记录以下具体内容：

- 统计张量、shape、校准 episode 清单和归一化方式；固定直方图 bin 数、原始范围以及对称/非对称 INT8 的整数范围。
- 对每个候选阈值 $\alpha$，用同一批校准激活构造参考直方图 $P_\alpha$；截断并按确定的量化/反量化规则构造重建直方图 $Q_\alpha$。记录零概率处理规则，计算 $D_{KL}(P_\alpha\Vert Q_\alpha)=\sum_i P_{\alpha,i}\log(P_{\alpha,i}/Q_{\alpha,i})$；同时计算 MSE 和饱和比例。候选范围与扫描步长须保存。
- 画出 **阈值—KL、阈值—MSE、阈值—饱和比例** 曲线，并标记所选阈值；说明选择最小 KL，还是因开发集动作质量改选邻近阈值。保存该阈值的 scale、zero point、截断比例及校准集重建误差。
- 在**留出测试 episode** 上报告该选择带来的激活/动作误差，并与 min/max 和 MSE clipping 在同一格式下对照；需要闭环和板端数据才能判断最终收益。不得用测试集挑 $\alpha$。

本项目已对一个 MLP 输入完成独立截断扫描，见[扩展 MLP 校准与截断](2026-09-27-mlp-calibration.md)；手写 KL 代理的最小值无效，RKNN 原生 KL 的内部阈值仍未知。不能把独立脚本曲线当成 RKNN 真正使用的阈值。
