# SO101 脚本专家仿真示教数据生成

日期：2026-10-15。目的：解决[仿真策略诊断](so101-sim-policy-diagnosis.md)中暴露的两个问题：成功示教太少（5段），以及没有偏离后的纠偏数据。本轮只生成和校验数据，**尚未用于训练**，没有任何模型成绩。

## 结论

- 训练划分400个种子中专家成功350段（87.5%），共104005帧。验证30个种子成功27段/6936帧，测试50个种子成功43段/10553帧。数据量要求“训练≥200段成功示教”已满足。
- 每帧包含顶视和腕部两路320×240 RGB（JPEG q90）、6维关节state、专家干净动作标签及实际执行命令。共1.8GB。
- 独立重放8段训练示教：按记录的执行命令从同一种子重放，8/8成功，state与记录最大差≤0.0011（数据集单位，度/夹爪百分点）。
- 专家失败集中在物体距底座>0.4m的区域：该区间训练种子成功34/67，0.35m以内成功257/265。所以存储的成功示教对远处物体覆盖偏少，这是数据分布偏差，不是策略结果。

## 专家原理

实现：`qvla/evaluation/so101_scripted_expert.py`（SHA256 `62f967fe…f94e`）。

1. **读取仿真真值**：物体位姿和目标位置只供专家计算动作；记录给策略的输入只有两路图像和6维关节state。
2. **抓取姿态**：TCP坐标系z轴为手指方向，x轴为夹爪开合方向（由活动爪随关节张开时沿-x移动实测确定）。5自由度臂的接近方向只能在过底座的竖直平面内倾斜，因此按倾角候选0.35–1.3rad选择最小可达倾角；用wrist_roll让开合轴的水平投影对准最近的方块面法线。
3. **IK**：在独立MjData上做40次阻尼最小二乘迭代（姿态权重0.15），从实测关节状态出发求下一参考点的关节目标，每步关节变化限幅4°。因为每步都从实测状态重新求解，标签是反馈动作。
4. **按进度推进的阶段**：预抓取→下降→闭爪（14步）→抬起→搬运→下降→缓慢部分松爪（24步开到0.55rad）→沿手指方向慢速后退→保持。到达判定为“参考点到位且TCP误差<6mm，或连续6步停滞”。抬起后未抓住、或搬运中掉落时重试一次。
5. **噪声（DART式）**：训练种子按`seed mod 3`分配0/1/2°的OU噪声（θ=0.15），只加在预抓取、抬起、搬运三个粗移动阶段的5个臂关节上。记录的`actions`是干净专家标签，`executed`是实际执行命令。训练数据中两者平均差0.42°，最大9.85°。

## 边界与后续

- 这是读取仿真真值的脚本专家，动作风格不同于人工遥操作和作者的10段示教。
- 测试划分的43段示教只能用于离线误差；闭环评测应使用全部50个测试种子，同时单列专家也失败的7个种子。测试数据不得用于训练、统计或选模型。
- 当前训练和评测代码只支持单顶视相机。使用这份数据需要先扩展为双相机输入（`observation.images.camera1/camera2`等映射需明确记录）。之后先做单场景/少场景过拟合检查，再全量训练。
- 图像为320×240，模型processor会再缩放并padding到512（或256）。这个分辨率差异需要和部署分辨率一起考虑。
- 尚未训练、未评测任何模型，也未做量化。

## 双相机训练流程与5段过拟合检查（2026-10-15）

- 训练沿用`finetune_so100_real.py`的flow matching、padding mask、优化器和保存规则；新增`camera_map`配置，并由`qvla/evaluation/finetune_so101_scripted.py`提供数据读取、prepare和闭环评测。映射：顶视→`observation.images.camera1`，腕部→`observation.images.camera2`。base的camera3不保留，也不复制视图。监督标签使用干净专家动作，不用带噪声的执行命令。
- 闭环评测：`env.reset(seed)`使用和生成时相同的相机配置；策略只得到两路图像、6维state和任务文本；10步Euler；每块执行50或10步；上限900步，成功后停止。固定推理噪声种子`900000+seed*100+chunk`。

### 下一步

- 训练量是主要瓶颈：本次约9.6万个样本，公开真机SO101 SmolVLA约256万个（40k×64），LeRobot默认20k×64。优先在GPUServer A10上做20k–40k步、更大batch的训练，并保存last和续训状态。
- 闭环默认改为执行10步或更少，并补充模拟推理延迟的异步评测。
- 若加长训练后wrist_roll仍是最大误差，再检查标签在±45°处折返和180°翻转造成的不连续，以及冻结VLM的影响。
- 测试集只在最终模型确定后评测一次。
